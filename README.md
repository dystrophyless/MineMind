# MineMind

MineMind - это современная версия "Сапера" для игроков, которым нравится не просто открывать клетки, а прокачивать стратегическое мышление, сравнивать результаты и возвращаться за ежедневным вызовом.

## Что мы сделали

Мы превратили классический Minesweeper в соревновательный продукт с профилем игрока, ежедневным испытанием, несколькими режимами и таблицами лидеров. Игрок может играть в привычный режим, пробовать игру без флагов, выживать 60 секунд в Timed Mode или проходить Daily Challenge с одной попыткой в день.

## Для кого это

MineMind сделан для людей, которым нравятся короткие, умные игровые сессии: любителей логических игр, фанатов "Сапера", игроков, которым важен прогресс, и тех, кто хочет соревноваться с другими без долгих матчей и сложного входа.

## Почему это ценно

Классический "Сапер" часто заканчивается одной партией без контекста. MineMind добавляет мотивацию возвращаться: сохраняет статистику, показывает личный прогресс, дает ежедневную цель и позволяет сравнивать себя с другими игроками в каждом режиме.

Игра остается простой и знакомой, но получает больше смысла: каждая партия влияет на профиль, рейтинг, серию и ощущение роста.
